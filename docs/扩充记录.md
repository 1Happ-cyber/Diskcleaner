# 扩充与验证记录

面向课程教师和项目学生，按轮次记录功能扩充、结构变化与真实验证结果。本文是 [中期报告](中期报告.md) 的补充材料，不替代报告本身。

## 第二轮（历史记录）

面向初版中期材料补充可演示功能与安全保护，未把缓存复用冒充增量扫描。

1. **目录空间可视化**：按扫描根目录的直属子目录递归汇总，根下文件单列；条形图显示前 12 项与其余合计。
2. **CSV 导出**：全部文件路径、字节数、修改时间、扫描取消标记；UTF-8 BOM、公式前缀防护、拒绝覆盖已有文件。
3. **重复副本选择**：按路径顺序每组保留第一份，只生成建议，不自动清理。
4. **副本保护**：阻止选择整组副本；确认前与后台清理前校验保留副本快照。

当时验证：19 项测试通过，另做了一次 Tk 窗口冒烟（扫描 → 渲染 → 查重 → 建议选择 → 切换图表），未调用真实回收站。

## 第三轮：结构调整、测试扩充与交付完善

### 3.1 新增模块

| 模块 | 类/函数 | 作用 |
|---|---|---|
| `analyzers.py` | `Analyzer`、`SizeRankingAnalyzer`、`TypeAnalyzer`、`DirectorySummary`、`AnalysisReport`、`Row` | 统一的分析器契约；界面只渲染报告 |
| `analyzers.py` | `DirectoryTree`、`TreeNode` | 目录树聚合，按层展开，避免一次性插入海量条目 |
| `tasks.py` | `TaskRunner` | 线程、事件队列、取消与 busy 状态；不依赖 tkinter |
| `policy.py` | `PathPolicy`、`ProtectedPathPolicy` | 拒绝清理系统目录与系统盘根目录 |
| `history.py` | `Snapshot`、`SnapshotStore`、`ChangeSet`、`HashCache`、`HistoryStore` | 快照、增量对比、哈希复用、结构化历史 |
| `shell.py` | `RecycleBinView` | 打开系统回收站，便于核对与恢复 |
| `diagnostics.py` | `missing_dependencies`、`summary` | 启动时依赖自检，缺失时中文提示并拒绝清理 |
| `formatting.py` | `human` | 统一大小格式化 |

### 3.2 新增功能

1. **目录树**：逐层展开，目录按占用降序；单层超过 500 个目录或 50 个文件时给出“另 N 个”提示。
2. **增量对比**：每次扫描与上次快照比较，状态栏与历史显示新增/修改/消失/未变数量。
3. **哈希复用**：大小与修改时间未变的文件在查重时不再读盘，状态栏显示“复用上次哈希 N 个文件”。
4. **受保护路径**：Windows、Program Files、ProgramData、系统盘根目录拒绝清理，批量检查时汇总被拒路径。
5. **回收站入口**：一键打开回收站，便于恢复。
6. **依赖自检**：启动即检查 Send2Trash；缺失时状态栏提示，清理按钮给出中文原因而不是逐个文件报 `ModuleNotFoundError`。
7. **历史升级**：JSONL 结构化字段（文件数、字节、变更统计、错误数、取消标记），跳过损坏行。

### 3.3 缺陷修复

| 问题 | 修复 |
|---|---|
| `total_size` 是每次全量求和的属性，界面渲染期间被多次调用 | 改为 `cached_property` |
| 进度回调被 GUI 二次过滤，文件数少于 100 时状态栏不动 | 扫描端按 0.2 秒或 100 个文件节流，GUI 不再过滤 |
| 清理页签靠索引 0/2 判断 | 改为按页签标题映射到表格 |
| 三个 bat 依赖 `py -3`，没有 Python Launcher 的机器直接失败 | `py` → `python` → `python3` 依次回落 |
| `0x400` 魔数重复出现 | 提取 `FILE_ATTRIBUTE_REPARSE_POINT` |
| CSV 覆盖时弹英文异常 | 导出前检查并给出中文提示 |
| 空闲状态进度条显示一段绿色 | 任务运行时才显示进度条 |
| 未安装 Send2Trash 时每个文件写一条失败 | 启动自检 + 清理前统一提示 |

### 3.6 已知限制与待办

- **单文件 exe 的临时目录限制**：`--onefile` 启动时要解压到 `%TEMP%`，在“禁止子进程写临时目录”的环境会报 `Could not create temporary directory!`；默认改为目录版，单文件版可用 `build.bat onefile` 生成，但目标机器 `%TEMP%` 必须可写。
- **数据目录回退**：默认 `%LOCALAPPDATA%/CourseDiskCleaner` 不可写时，自动改用程序目录下的 `DiskCleanerData`，并在信息页注明；这是为受限环境增加的回退，不改变正常环境的默认位置。
- **真实回收站移入与恢复**：脚本已能识别“文件消失但回收站无记录”的情况；AI 开发会话的受限进程里 `send2trash` 正是这种表现，脚本判定失败。需在普通命令行重跑一次作为真实验收结论。
- **无权限目录、目录联接、百万文件性能**：需要真实桌面环境与可丢弃样本。
- **增量对比不是增量遍历**：目录仍要枚举、文件仍要 `stat`，省掉的是内容读取；报告中已如实说明。
- **快照与历史无自动轮转**：长期使用会持续增长，后续可加上限或压缩。
- **TOCTOU**：`stat` 校验与回收站调用之间仍有竞争窗口，不承诺抵御恶意并发替换。
